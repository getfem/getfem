************************
  What's New in |gf| 5.6
************************

The main contribution of this version is a series of corrections and a few optimizations following an analysis of the code with Claude AI.

Released version, 2026/11/24.

The main changes are:

   * A series of bug fixes and code improvements.

   * In GWFL, the term 'Normal' now also refers to the unit normal in the interior of a codimension 1 element (1D element in 2D, and 2D element in 3D).

   * The new GWFL term 'element_curvature' gives the Euclidean components of the curvature tensor in such codimension 1 elements.

   * Raytracing for contact conditions extended to shell elements.

   * A better account of tensor symmetry and tensor sparsity in the optimization of elementary computations in the generic assembly.

   * The Octave/Matlab interface plot facilities have been ported to the Python interface.

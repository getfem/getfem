************************
  What's New in |gf| 5.6
************************

The main contribution of this version is a series of corrections and a few optimizations following an analysis of the code with Claude AI.

Released version, 2026/28/11.

The main changes are:

   * A series of code corrections and improvements

   * In GWFL, the term 'Normal' now also refers to the unit normal inside an element of codimension 1 such as a 3D surface element and the term 'element_curvature' gives the euclidean components of the curvature tensor of such an element.

   * Raytracing for contact conditions ported to shell elements.
     
   * A better account of tensor symmetry and tensor sparsity in the optimization of elementary computations in the generic assembly.
     
   * The Octave/Matlab interface plot facilities has been ported to the Python interface.
